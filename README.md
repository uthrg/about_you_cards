# 🌙 關於你，我還不知道的事 (About You Cards)

一款適合深夜聚會、朋友談心、伴侶交流的線上對話卡牌遊戲。  
透過**「故事卡、選擇卡、延伸卡、猜猜卡」**四種牌型，以及每張卡牌附帶的**「💡 回答方向提示」**與**「💬 延伸問題」**，讓彼此在沒有壓力的氛圍下，聊出平常不會提起的故事與想法。

---

## ✨ 遊戲核心原則

1. **真誠但不勉強**：如果抽到暫時不想回答的題目，隨時可以點擊底部**「抽下一張卡 / 跳過」**，不需要解釋原因。
2. **傾聽大於評價**：當對方分享時，先專注傾聽對方的經歷與感受，不急著給建議或下判斷。
3. **每一題都有「提示」與「延伸問題」**：
   - **💡 回答方向提示 (`answerGuidance`)**：不知道怎麼開頭、腦袋一片空白時，點開提示就能看到具體的生活例子與切入角度。
   - **💬 延伸問題 (`followUpQuestions`)**：當對方分享完第一輪後，現場玩家可以點開延伸問題繼續往下聊，讓話題自然深入。

---

## 🃏 主題牌堆與卡牌架構

畫面上方的牌堆分類專注於**「起手題目」**，包含四大主題牌堆；而**「延伸卡」**則作為聊完題目後的專屬追問牌庫：

### 1. 📖 故事卡 (`story`)
- **玩法**：抽卡者閱讀題目，分享一段自己的真實經歷、習慣或記憶。
- **特色**：
  - 內建**「💡 不確定怎麼開頭？點此看回答方向提示」**，提供多個生活情境範例幫助回想。
  - 分享完後可展開**「💬 延伸問題」**，或從下方推薦清單抽取配對的**延伸卡**。

### 2. 🧭 選擇卡 (`choice`)
- **玩法**：閱讀人生與價值觀題目與 `A / B / C / D` 四個選項，先選擇最符合自己直覺的做法。
- **兩階段互動**：
  1. **先說原因**：選好選項後，先和大家分享「為什麼我會這樣選」。
  2. **再看動機解析**：點擊「查看可能的動機解析」，看看自己潛在的考量點與在意的價值觀。

### 3. ⚔️ 情境卡 (`scenario`)
- **玩法**：置身於具體的人際衝突、道德兩難或突發狀況中（例如越界玩笑、算錯找錢、記憶消除按鈕等），做出最本能的反應。
- **特色**：提供話題發展方向指引，幫助大家從情境延伸到真實生活的相處界線。

### 4. ❓ 猜猜卡 (`guess`)
- **玩法**：透過猜測彼此的反應與習慣，發現「我以為的你」和「真實的你」之間有趣的差異。
- **進行步驟**（點擊步驟可打勾標記）：選擇主角 → 眾人猜測 → 主角親自揭曉原因。

---

## 💬 延伸卡牌庫（追問工具牌）

> **「延伸卡不應該直接在主牌堆裡被盲抽，而是當有人聊完一題時，配對出最合適的視角繼續深聊。」**

在翻開的每一張卡片下方，皆設有**「🃏 搭配延伸卡繼續聊」**區塊：
- 系統會根據當前題目主題，智能推薦 2～3 張最合適的延伸卡（例如聊到遺憾時推薦 `NO. 43 那個瞬間`、`NO. 50 沒有說出口的話`）。
- 點擊推薦按鈕或點擊**「隨機抽延伸卡」**，會開啟專屬的延伸卡視窗，提供：
  - 📌 **適合使用的時機 (`useWhen`)**
  - 💬 **換個方式問 (`alternativePrompts`)**
  - 💡 **回答思考方向提示 (`answerGuidance`)**
  - 「🎲 換一張延伸卡」按鈕，讓現場朋友挑選最想追問的角度。

---

## 🌟 話題深度分級 (`Depth 1 ~ 3`)

背景星空色調會隨當前卡牌的深度等級自然轉變：

| 深度 | 適合時機 |
| :--- | :--- |
| **Depth 1（微光）** | 剛開局破冰、認識新朋友、輕鬆日常話題 |
| **Depth 2（夜色）** | 氣氛漸熱、聊聊彼此的習慣、價值觀與人際相處 |
| **Depth 3（星空）** | 深夜談心、彼此信任度高，探索內心深處的遺憾、轉折與真心話 |

---

## 🎮 建議遊玩流程（2～6 人）

1. **決定順序**：順時針輪流當「抽卡人」，或由上一位回答完的人指定下一位。
2. **點擊翻牌**：輪到你時，點擊畫面中央蓋著的卡牌背面，3D 翻開題目。
3. **分享與交流**：抽卡者分享經歷或選擇；若一時想不到切入點，點開**「💡 回答方向提示」**。
4. **追問推進**：回答完後，其他人可以點擊卡片下方的**「💬 搭配延伸卡」**或底部的**「抽延伸卡」**，挑選一張合適的追問視角，讓對話自然走深一步。
5. **下一回合**：點擊底部**「抽下一張卡 / 跳過」**，牌堆洗入下一張蓋著的新卡交給下一位玩家。

## 📂 題庫資料結構 (`src/data/*.json`)

- `src/data/storyCards.json`：故事卡（35 張）
- `src/data/choiceCards.json`：選擇卡（21 張）
- `src/data/scenarioCards.json`：情境卡（9 張）
- `src/data/guessCards.json`：猜猜卡（9 張）
- `src/data/followupCards.json`：延伸追問卡（12 張專屬伴侶庫）

### 欄位規範範例
```json
{
  "id": 1,
  "type": "story",
  "category": "分類名稱",
  "title": "卡片標題",
  "question": "主要問題內容",
  "answerGuidance": [
    {
      "title": "提示分類（例如：生活習慣）",
      "examples": ["具體提示範例 1", "具體提示範例 2"]
    }
  ],
  "followUpQuestions": [
    "延伸問題 1",
    "延伸問題 2",
    "延伸問題 3"
  ],
  "depth": 1
}
```
